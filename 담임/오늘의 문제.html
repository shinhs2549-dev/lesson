'짐'은 누구일까?

④9품중정제를 폐지하였다.
'짐' = 수 문제(양견)

단서

  • 제왕을 칭하는 자가 여럿 → 남북조 분열을 끝내고 통일
  • 도량형 통일, 새 동전 주조
  • 수도에서 통관까지 광통거 착공 → 수 문제의 운하
  • 장성 너머 북방 유목 민족 정벌 → 돌궐

선지 주인공

  • ①군기처 설치 — 청 옹정제
  • ②분서갱유 — 진 시황제
  • ③국호를 원으로 — 쿠빌라이 칸
  • ④9품중정제 폐지, 과거제 실시 — 수 문제
  • ⑤장건 서역 파견 — 한 무제

함정: '통일·도량형·장성'만 보면 진시황(②)처럼 보이지만, 결정적 단서는 광통거예요.

문제 2 · 수학 · 4점 · 단답형

값을 구하시오

98

풀이

  1. 주기 찾기: an+3 = an+9 = an → 주기 3
    a1=p, a2=q, a3=r로 두기
  2. (가) a5=q, a6=r, a10=p
    → 3(p+q)+2r = 11
  3. (나) 합: 20 = 3×6 + 2
    → 7(p+q)+6r = 26
    연립하면 p+q = 7/2, r = 1/4
  4. (나) 로그: 35 = 3×11 + 2
    → p12q12r11 = 2−10
    r11 = 2−22이므로 pq = 2
  5. 구하는 값: 한 주기 = (p+q+r)/(pqr) = 15/2
    40 = 3×13 + 1 → 13 × 15/2 + 1/(pq)
    = 195/2 + 1/2 = 98

함정: p, q를 하나씩 구하려 하면 (7±√17)/4라는 무리수가 나와 막혀요. p+q와 pq만 있으면 충분합니다.
